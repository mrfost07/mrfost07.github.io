Which installer should I choose?

In Windows, open Settings → System → About and look for System type. Match the processor type to x64 or ARM64.

Verify an installer

Run Get-FileHash .\Folio_Setup_1.5.9_x64.exe -Algorithm SHA256 in PowerShell, substituting the downloaded filename if needed. This release uses unsigned installers. Compare the result with the SHA-256 file for the same installer.
